Eerst de database uitbreiden met de kilometerstanden. Daarna passen we de website aan. Stap 1 — Supabase database Ga naar: Supabase → SQL Editor → New query Plak daar dit: alter table public.reizen add column start_km integer, add column eind_km integer; Klik daarna op Run. Als je onderaan ziet: Success. No rows returned dan is het goed. Dat betekent dat de twee nieuwe kolommen zijn toegevoegd. Daarna Ga naar: Table Editor → reizen Je zou naast de bestaande velden nu ook moeten zien: start_km eind_km Doe alleen deze stap eerst. Stuur me daarna eventueel een screenshot of zeg "gelukt". Dan doen we stap 2: de twee invoervelden in Reizen zetten en automatisch KM gereden laten berekenen. 🚐📏 gelukt Top. 👍 Dan staat de database goed. Stap 2 — website aanpassen Nu gaan we de invoer uitbreiden met: Start KM Eind KM KM gereden → automatisch berekend Ik zou KM gereden niet als invoerveld maken. De app rekent die zelf uit: eind KM - start KM Dus als je invult: Start: 12.450 Eind: 13.185 dan toont de app automatisch: 735 km gereden Eén belangrijke keuze Ik zou de kilometerstand ook controleren: Eind KM lager dan Start KM → foutmelding Eind KM gelijk aan Start KM → 0 km Lege waarden → toegestaan, bijvoorbeeld als je alleen een camperplaats registreert Dat voorkomt dat er straks per ongeluk -450 km in het logboek staat. 😄 Volgende stap: ik kan je nu de aangepaste index.html geven zodat je hem in GitHub vervangt. Daarbij blijven onze huidige Supabase-login en databasekoppeling gewoon intact. graag Klaar. 👍 Ik heb v0.3 met kilometerregistratie gemaakt. Download B66 – Making Memories v0.3 Wat is erbij gekomen? Bij Reizen staat nu: Start KM Eind KM KM gereden → automatisch berekend Bijvoorbeeld: Start: 12.450 km Eind: 13.185 km 735 km gereden Ook zit er een controle in: als je per ongeluk een eindstand lager dan de beginstand invult, geeft de app een waarschuwing. De kilometerstanden worden bovendien mee opgeslagen in Supabase, dus ze blijven onderdeel van het reislogboek. Nu weer naar GitHub Net als de vorige keer: Open GitHub → b66-making-memories Klik op index.html Klik op het potloodje ✏️ Ctrl+A Open het gedownloade bestand hierboven op je pc. Open het met Kladblok/Notepad. Ctrl+A → Ctrl+C Ga terug naar GitHub → Ctrl+V Commit changes Daarna wachten tot GitHub Pages klaar is en Ctrl+F5 op de website. Dan testen we bijvoorbeeld: Start KM: 12.450 Eind KM: 13.185 en kijken we of hij 735 km gereden toont én de waarden in Supabase terechtkomen.
